fastfetch

System info splash tool for ForgeOS. Prints the Rivet mascot in ASCII next to your OS, kernel, and shell details.

forge:~
forge:~$ fastfetch ______ /|_||_\`.__ ( _ _ _\ =`-(_)--(_)-' F O R G E OS: ForgeOS x86_64 Kernel: forge-kernel (custom, C + asm) Shell: forge-sh (builtin) Mascot: Rivet the anvil-bot Arch: x86_64 (long mode) Filesys: ramfs (volatile) Pkg Mgr: fpkg

Install

fpkg install fastfetch

Once installed, run it from the shell:

forge:~$ fastfetch

Why "kernel-builtin"?

ForgeOS doesn't have a userspace or an ELF loader yet, so packages like this one can't run as standalone programs — they integrate as a shell command compiled directly into the kernel. Installing this package today means copying its source into kernel/, wiring one function call into the shell's command dispatcher, and rebuilding. The packaging guide covers this in full, and explains what changes once ForgeOS gets real userspace processes.
