Publishing your own

Packages are plain tarballs (.tar.gz, referred to as .fpk in ForgeOS's own tooling) with a manifest.json inside. There's no build server and no submission review — publishing means committing a file and updating the index.

  1. Package your files into a tarball with a manifest.json at the root.
  2. Commit it to forge-packages/packages/ on GitHub.
  3. Add an entry to packages.json with the download URL and a sha256 checksum.
  4. Push. The package is live as soon as GitHub Pages rebuilds — usually under a minute.

See the packaging guide for the full manifest format.
